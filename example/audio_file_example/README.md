# Audio file example (V1)

Demonstrates synchronous and streaming recognition of WAV or FLAC files with the Google Cloud Speech-to-Text V1 API.

From this directory, run `flutter pub get` and `flutter run`. Configure valid credentials locally and make sure the recognition encoding and sample rate match the selected audio file. Never commit service-account credentials.

See the package [README](../../README.md) for complete setup and security guidance.
